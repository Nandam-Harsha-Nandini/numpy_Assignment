This repository contains my NumPy practice and preparation.

## 📌 File

- `HarshaNandini_numpy.ipynb` – NumPy concepts, practice questions, coding problems, and scenario-based challenges.

## 📚 Topics Covered

### Section A – NumPy Fundamentals
- NumPy arrays vs Python lists
- Vectorization
- Element-wise multiplication and matrix multiplication
- Broadcasting
- `flatten()` vs `ravel()`
- NumPy axes (`axis=0` and `axis=1`)
- Normalization and standardization
- Handling `NaN` values
- RGB image shapes
- Reproducibility using random seeds

### Section B – Output Prediction
- Broadcasting and array shapes
- Array slicing
- Boolean indexing
- Matrix multiplication
- `np.mean()` and `np.nanmean()`
- `np.where()`
- Array dimensions and size
- Array reversing

### Section C – Coding Practice
- Score classification using `np.where()`
- Z-score standardization
- Combining batches using `np.vstack()`
- Feature-wise standardization
- Linear prediction using `X @ w + b`
- Mean Squared Error (MSE)
- Random data generation using `default_rng()`
- Image normalization
- Image batch averaging

### Section D – Applied / Scenario-Based Problems
- Data preprocessing pipeline
- Detecting and handling missing values
- Standardizing cleaned data
- Understanding RGB image batches
- Computing an average image
- Debugging model code
- Understanding array shapes and operator precedence

### Section E – Bonus / Challenge
- Per-column Min-Max normalization
- Three-level score classification using nested `np.where()`
- Fully vectorized NumPy operations without explicit loops
